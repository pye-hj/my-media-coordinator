# 表示機能：月齢

ダイジェストの日付の月齢と月相（新月・三日月・満月など）、次の満月・新月までの日数を表示する。外部のデータは使わず、計算だけで求める。

## 設定（profile.md の `## 表示機能`）

```markdown
- 月齢: on
```

設定項目はない（地域によらない）。このため、この節に項目の表は無い。

## 手順

次のコマンドを**そのまま単独で**実行する（`cd` や `&&`、パイプと組み合わせない）。

```bash
python3 .claude/skills/news-digest/features/moon.py YYYY-MM-DD
```

- 標準出力の `<section class="feature moon">…</section>` を、手を加えずにダイジェストに入れる。
- 終了コード 2 は引数の誤り。日付を直して1度だけやり直す。

## issue の本文

断片の `.summary` の行（例：`🌓 月齢 7.9　上弦の月`）から絵文字を除いた形で、対象期間の次の行に書く。

```markdown
月齢: 7.9（上弦の月）
```
