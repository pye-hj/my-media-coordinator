# 表示機能：天気

指定した1地域の、ダイジェストの日付の予報を、時刻ごとの表（天気のアイコン・気温・降水確率）で表示する。

## 設定（profile.md の `## 表示機能`）

```markdown
- 天気: on（地域: 札幌市）
```

括弧内に `、` 区切りで書く。

| 項目 | 必須 | 意味 |
|---|---|---|
| `地域` | ○ | 表示する地域。見出しにもこの名前を使う。国外でもよい |
| `緯度経度` | | `43.06, 141.35` の形式。省略時は `地域` から自分で決める（市区町村なら役所の所在地あたりでよい） |
| `間隔` | | 表の間隔（時間）。`1` `2` `3` `4` `6` のいずれか。既定は `3` |

`地域` が無い、または地域を特定できない場合は、この機能を無効として扱い、最後の報告でそのことを伝える。

## 手順

次のコマンドを**そのまま単独で**実行する（`cd` や `&&`、パイプと組み合わせない）。地域名に空白を含むときは `"` で囲む。

```bash
python3 .claude/skills/news-digest/features/weather.py YYYY-MM-DD 緯度 経度 地域名 --step 間隔
```

- 標準出力の `<section class="feature weather">…</section>` を、手を加えずにダイジェストに入れる。
- 終了コード 3（予報を取得できなかった）でも、出力された断片（取得できなかった旨の表示）をそのまま入れ、最後の報告でエラー内容を伝える。やり直しは繰り返さない。
- 終了コード 2 は引数の誤り。引数を直して1度だけやり直す。

## issue の本文

成功した場合は、断片の `.summary` の行（例：`🌧️ 弱い雨　最高 6℃ / 最低 1℃ / 降水確率 最大 85%`）の先頭に地域名を付け、対象期間の次の行に書く。

```markdown
天気（札幌市）: 🌧️ 弱い雨　最高 6℃ / 最低 1℃ / 降水確率 最大 85%
```
