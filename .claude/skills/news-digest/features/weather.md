# 表示機能：天気

指定した1地域（日本国内）の、ダイジェストの日付の気象庁の予報を、時刻ごとの表（天気のアイコン・気温・降水確率）で表示する。

## 設定（profile.md の `## 表示機能`）

```markdown
- 天気: on（地域: 札幌市）
```

括弧内に `、` 区切りで書く。

| 項目 | 必須 | 意味 |
|---|---|---|
| `地域` | ○ | 表示する地域。日本国内の市区町村名（`東京都千代田区`、`札幌市` など）か都道府県名。同名の市町村がある場合は都道府県名から書く。見出しにもこの名前を使う |
| `間隔` | | 表の間隔（時間）。`3` `6` のいずれか。既定は `3` |

`地域` が無い、または国外の地域の場合は、この機能を無効として扱い、最後の報告でそのことを伝える。古い profile.md に残っている `緯度経度` は使わない（無視する）。`間隔` が `3` `6` 以外なら `3` とみなす。

予報は気象庁が地域（府県をいくつかに分けた区域）ごとに出すもので、表の気温はその区域の代表地点のもの。時刻ごとの予報は3時間刻みで、発表時刻より前の時間帯と翌日より先は `–` になる。

## 手順

次のコマンドを**そのまま単独で**実行する（`cd` や `&&`、パイプと組み合わせない）。地域名に空白を含むときは `"` で囲む。

```bash
python3 .claude/skills/news-digest/features/weather.py YYYY-MM-DD 地域名 --step 間隔
```

- 標準出力の `<section class="feature weather">…</section>` を、手を加えずにダイジェストに入れる。
- 終了コード 3（予報を取得できなかった）でも、出力された断片（取得できなかった旨の表示）をそのまま入れ、最後の報告でエラー内容を伝える。やり直しは繰り返さない。
- 終了コード 2 は引数の誤り。地域を特定できない場合もこれで、標準エラーに理由（候補があれば候補）が出る。候補や都道府県名を手がかりに地域名を直して1度だけやり直す（見出しには `地域` の名前を使いたいので、直した名前で見出しが変わるのは構わない）。それでも失敗したら、この機能を無効として扱い、最後の報告で伝える。

## issue の本文

成功した場合は、断片の `.summary` の行（例：`🌧️ 雨 時々 くもり　最高 6℃ / 最低 1℃ / 降水確率 最大 80%`）の先頭に地域名を付け、対象期間の次の行に書く。

```markdown
天気（札幌市）: 🌧️ 雨 時々 くもり　最高 6℃ / 最低 1℃ / 降水確率 最大 80%
```
