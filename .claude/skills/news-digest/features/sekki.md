# 表示機能：二十四節気

ダイジェストの最後に、その日の二十四節気と七十二候、季節の移ろいを感じる短い文章を添える。節気・候の名前と日付は外部のデータを使わず計算で求め、文章はダイジェストを書くときに添える。

## 設定（profile.md の `## 表示機能`）

```markdown
- 二十四節気: on
```

設定項目はない（地域によらない）。このため、この節に項目の表は無い。

## 置き場所

記事の最後（セレンディピティ枠の `article` の後）。

## 手順

次のコマンドを**そのまま単独で**実行する（`cd` や `&&`、パイプと組み合わせない）。

```bash
python3 .claude/skills/news-digest/features/sekki.py YYYY-MM-DD
```

- 標準出力の `<section class="feature sekki">…</section>` をダイジェストに入れる。`{{essay}}` だけを下の「文章」で置き換え、ほかには手を加えない（名前・読み・日付・日数を書き直さない）。
- 終了コード 2 は引数の誤り。日付を直して1度だけやり直す。

## 文章（`{{essay}}`）

ニュースを読み終えたあとに、季節の移ろいを味わえる短い文章。情報を足すことより、読んで季節を感じられることを大事にする。

- 日本語で2〜4文。今の候（`.kou`）と節気（`.summary`）を軸にする。候の名前の情景を、今の暮らしの中でどう感じられるかに結びつける。
- 題材は、旬の食べもの、草木や花、鳥や虫、行事や年中行事、暮らしの習わし、空や風の様子などから一つ二つ。
- 前回のダイジェスト（`digests/` の最新のもの）に `.essay` があれば読み、同じ題材・同じ言い回しを繰り返さない。同じ候が続く日も、毎回違う角度から書く。
- `今日から` の印がある日（節入り・候の変わり目）は、季節が一歩進んだことを書き出しにしてよい。
- 天気の機能が on ならその日の予報に、天気の話題が記事にあればそれに軽く触れてよい。ただし数字は書き直さず、雰囲気だけにする。
- 一般に知られた季節の知識の範囲で書く。出典の要る具体的な出来事や数字は書かず、出典番号も付けない。ニュースの要約や「見立て：」は書かない。
- 説教や教訓めいた結びにしない。文末の「〜ですね」「〜しましょう」の多用を避ける。
- `&` `<` `>` `"` はエスケープする。タグは使わない。

## issue の本文

`.summary` の節気名と `.kou` の候を、対象期間の次の行に書く（文章は載せない）。

```markdown
二十四節気: 小雪・初候 虹蔵不見
```
